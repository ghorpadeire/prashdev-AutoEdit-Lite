- Engagement: the edit should feel energetic, not sluggish

LIGHT MODE instructions:
- Only remove segments with obvious mistakes (speaker corrects themselves, clearly restarts a sentence)
- Only remove exact duplicate takes (same point made twice back-to-back)
- Keep everything else, including minor filler words and small tangents
- When in doubt, KEEP the segment

BALANCED MODE instructions:
- Remove all mistake/restart segments
- Remove all duplicate takes — keep the best version of each point
- Remove heavy filler word segments (sentences that are more than 30% "um", "uh", "like", "you know", "sort of", "kind of")
- Remove minor tangents that do not contribute to the main topic
- Remove pauses longer than 3 seconds (these are handled by timestamp gaps, not text)
- When in doubt, KEEP the segment

AGGRESSIVE MODE instructions:
- Apply all BALANCED rules strictly
- Remove any segment that is not essential to the core message
- Remove transitional filler ("so...", "okay so...", "anyway...", "right so...")
- Remove rhetorical repetition (same point made in slightly different words)
- Aim for the tightest possible cut that preserves full meaning
- When in doubt, REMOVE the segment
